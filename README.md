# student-marks-calculator
my first python project - student marks project


## About
A beginner-friendly Python application that calculates a student's total marks, percentage, and pass/fail result.

## Features
- Accepts student name
- Takes marks for three subjects
- Calculates total marks
- Calculates percentage
- Validates marks (0–100)
- Checks individual subject passing criteria
- Displays the final result

## Technologies Used
- Python 3

## How to Run
1. Install Python 3.
2. Download `student_marks_calculator.py`.
3. Run the following command:

```bash
python student_marks_calculator.py
```
